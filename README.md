## About

Extends Hibernate mapping knowledge to many-to-many relationships. This assignment covers join tables, bidirectional associations, and managing complex entity graphs with Hibernate/JPA.

## Key Concepts

- `@ManyToMany` annotation and join tables
- `@JoinTable` and `@JoinColumn` configuration
- Bidirectional many-to-many with `mappedBy`
- Managing association lifecycle and orphan removal
